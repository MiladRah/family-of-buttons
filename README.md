## Run it
- Online: open the link above.
- Locally: download the repo and double-click `index.html` (no install or build step).

## How to use
- Drag any two buttons into the box to compare interests (shared in the middle, unique on each side).
- Tap/click a button to open that person's page.
- × removes a button from the box; **Clear** empties it.

## Structure
```
index.html, style.css, script.js   ← home page (the family of buttons)
annas/   hafiz/   mo/   milad/     ← each member's personal page (index.html + its files)
```
The links and interests for the home page live in the `PEOPLE` list at the top of `script.js`.
