Hafiz - Explorer's Page (converted from Figma)

HOW TO VIEW
  Double-click index.html. It opens in your default browser (Chrome, Edge, Safari, Firefox).
  Keep the folder structure as-is: index.html needs the css/ and images/ folders next to it.
  Resize the browser window to see how the layout adapts (3 columns -> wraps -> 1 column on phones).

WHAT'S INSIDE
  index.html        page structure and text
  css/style.css     all styling (colors, fonts, spacing, layout)
  images/           background photos and profile portraits

EDITING
  Open index.html or css/style.css in any text editor (e.g. VS Code, Notepad), save, and refresh the browser.
  Fonts (Inter, Outfit, Platypi) load from Google Fonts, so an internet connection is needed for exact fonts.
